## KB-DL-01: Timeout or CDN error when downloading course code assets
Course files such as code assets and slides are served from a content delivery network (CDN). A timeout while downloading usually means a slow or interrupted connection to the nearest CDN server. Retry on a different network (for example a mobile hotspot), disable your VPN, and use a desktop browser for large files. Download managers that support resume also help. If the same file always times out on several networks, report the course name and file name to support so the file can be checked.

## KB-DL-02: Large downloads stop or fail partway
Files larger than 500 MB can fail if your connection drops. Use a stable wired or Wi-Fi connection, pause other downloads, and keep the tab open until the file finishes. Browsers that support resumable downloads (Chrome, Edge) let you press Resume in the downloads list rather than starting again.

## KB-DL-03: Downloaded ZIP file is corrupted or will not open
A ZIP that will not open usually did not finish downloading. Delete it and download again, and compare the file size with the size shown on the course page. Extract with a current tool such as 7-Zip. If the file size matches and extraction still fails, report the course name and file name to support.
